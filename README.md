# Juligram-chess

A local-first, offline chess experience built for tournament play, custom time controls, and peer-to-peer clip sharing.

Juligram-chess is designed for players who want a private, fast, and reliable chess app that works without requiring a cloud backend. It supports local gameplay, flexible tournament workflows, custom timing settings, and easy sharing of memorable game moments between nearby devices.

## Features

- Offline-first chess gameplay
- Tournament modes for structured play
- Custom time controls
- Responsive design for desktop and mobile devices
- Peer-to-peer clip sharing
- Fast, local-first experience with no required internet connection
- Built and maintained by Julian

## Mobile support

Juligram-chess is designed to work on mobile devices as well as desktop environments, with a responsive layout that adapts to smaller screens. This makes it suitable for:
- on-the-go chess play
- local club or tournament use
- quick matches from a phone or tablet
- portable use without needing a fixed workstation

## Why Juligram-chess?

Unlike many chess apps that depend on online services, Juligram-chess focuses on:
- privacy
- offline reliability
- local control of game data
- flexible tournament settings
- easy sharing of critical moments
